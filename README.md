# Digital Mandi OS

A mobile-first operating system for arhtiya/commission-agent mandi operations.

## Product scope
- Crops: Paddy (धान), Wheat (गेहूँ), Gram (चना)
- Commission and own-trading business models
- Miller-paid commission: fixed per quintal + percentage, with configurable weight basis
- Separate Farmer Slip and Miller Slip
- Party ledgers, stock, dispatch, reconciliation, payments and accounting

## Stack
React + TypeScript + Vite, Cloudflare Pages, Workers and D1 (planned). This repository starts with the frontend foundation and schema blueprint.

## Local development
```bash
npm install
npm run dev
```
